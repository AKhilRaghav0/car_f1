## 🖼️ **Texture Specifications**

### **Main Car Texture (`car_f11.png`)**
- **Size**: 64x64 pixels (recommended)
- **Format**: PNG with transparency support
- **Usage**: Applied to the 3D car model

### **Inventory Icon (`car_f1_inventory.png`)**
- **Size**: 16x16 pixels
- **Format**: PNG with transparency support
- **Usage**: Shown in player inventory and crafting

### **New Item Textures**
- **Size**: 16x16 pixels
- **Format**: PNG with transparency support
- **Style**: Match the existing texture style

## 🎯 **Texture Features**

- **High Quality**: Sharp, clear textures for better visual appeal
- **Consistent Style**: All textures follow the same artistic direction
- **Transparency Support**: PNG format for clean edges
- **Scalable**: Textures work well at different resolutions

## 🔧 **Creating Missing Textures**

### **Fuel Can Texture**
- Create a 16x16 pixel steel can with fuel indicators
- Use metallic colors (silver, gray)
- Add fuel level markings or symbols

### **Repair Kit Texture**
- Create a 16x16 pixel toolbox or wrench design
- Use tool-like colors (brown, black, silver)
- Add repair symbols or cross symbols

## 📝 **Notes**

- The mod will work without the new texture files, but items will use default textures
- You can use the existing `car_texture_template.png` as a base for new textures
- All textures are automatically loaded by the mod
- Consider creating texture variants for different car states (damaged, fueled, etc.)

## 🎨 **Texture Style Guide**

- **Colors**: Use the existing color palette from `car_f11.png`
- **Shading**: Add depth with highlights and shadows
- **Details**: Keep details visible at small sizes
- **Consistency**: Match the overall mod aesthetic
